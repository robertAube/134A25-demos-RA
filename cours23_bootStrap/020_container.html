.container

La classe container est utilisée pour créer un conteneur centralisé dans la page. Elle sert à :
-   Encadrer le contenu avec des marges automatiques à gauche et à droite.
-   Limiter la largeur du contenu selon la taille de l’écran (responsive).
-   Elle est souvent utilisée comme élément de base pour structurer une page.

.bg-info

La classe bg-info est une classe utilitaire de couleur de fond.
Elle applique une couleur d’arrière-plan bleue claire (dans le thème Bootstrap par défaut).
